# 低温水獭在线内容项目

这是“低温水獭”抖音图文账号的统一内容项目，用于在多台设备之间同步：

- 已做、制作中和候选选题，防止重复。
- 来源视频、人物和核心观点。
- 黑金访谈版式、Logo与字体规范。
- 标题、正文、话题和首评风格。
- 字幕拼图工具和 YouTube 视频帧截图扩展。

## 每次工作的正确顺序

1. 同步远程仓库。
2. 阅读 `AGENTS.md` 和三张台账。
3. 查重后，将选题状态改为“制作中”并同步。
4. 用 YouTube Screenshot 扩展获取每页一张高清人物帧。
5. 按黑金访谈版式生成图片和发布文案。
6. 发布后补全来源、时间、链接和数据表现，再次同步。

## 本地与在线的边界

GitHub 保存规则、台账、文案、脚本、Logo、模板和轻量工具。完整视频、临时下载、原始截图和批量输出不进入 GitHub，避免仓库膨胀。

## 另一台设备接入

在另一台设备克隆同一私有仓库，并在 Codex 中把仓库根目录设为项目主文件夹。Codex会自动读取根目录的 `AGENTS.md`。
